# 하율 주간 공부 계획표

초등학교 6학년용 주간 공부 체크리스트입니다. **기존 요일별 일정은 그대로 유지**하고, **수매싱연산 중1-1만 40분**으로 수정한 버전입니다.

## 바로 사용하기
- **웹사이트:** https://jaydendom27-web.github.io/hayultodo/
- 요일을 선택해 할 일을 체크하고, 실제 걸린 시간을 분 단위로 입력합니다.
- 이전 주·다음 주를 이동하면 주차별 기록을 볼 수 있습니다.
- 상단 **PDF로 저장 / 인쇄하기** 버튼으로 A4 2쪽짜리 주간 계획표를 출력할 수 있습니다. PDF는 인쇄 창에서 'PDF로 저장'을 선택합니다.

## 저장 및 주의사항
- 체크 내역·실제 공부 시간·메모는 **현재 브라우저의 로컬 저장소(localStorage)**에만 보관됩니다.
- 다른 기기 또는 브라우저와 자동 동기화되지 않으며, 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.
- 서버 계정 등록이나 개인정보 전송 기능은 없습니다.
- **일요일 CMS 클리닉 + 수매싱 2-1**은 요청하신 기존 일정에 따라 포함되어 있습니다. 매주 진행되는 수업은 아니므로 필요에 따라 그 주에 체크하세요.

- `README.md`: 사용 안내
