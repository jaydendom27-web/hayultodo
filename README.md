# 하율 주간 공부 계획표

**웹사이트:** https://jaydendom27-web.github.io/hayultodo/

초등학교 6학년용 일주일 학습 체크리스트입니다. 기존 요일별 일정은 유지하고, 수매싱연산 중1-1의 목표만 **40분**으로 수정했습니다.

## 가족 공유 사용법

1. 부모님이 웹사이트에서 **가족 계정 만들기**를 선택해 부모님 이메일·비밀번호로 가입합니다.
2. Supabase에서 인증 메일이 오면 이메일을 확인하고 사이트로 돌아와 **로그인**합니다.
3. 아들 휴대폰에서도 **같은 가족 계정**으로 로그인합니다. 별도 아들 이메일은 필요 없습니다.
4. 각 요일의 완료 체크·실제 소요시간·한마디를 입력하면 서버에 저장됩니다.
5. 다른 기기에서는 **기록 새로고침**으로 즉시 확인하거나 최대 약 15초 간격으로 자동 새로고침됩니다.
6. 과거에 브라우저에 저장한 기록이 있고 서버에는 아직 해당 주 데이터가 없다면 **이 기기의 이전 기록 가져오기**를 누르세요.

## 기능

- 월~일 요일별 일정, 완료 체크, 목표와 실제 공부시간 비교
- 주간 진행률과 총 학습시간
- A4 2쪽 PDF 저장 및 인쇄
- 로그인 계정 기준으로 주차별 기록 보관·공유

## 보안 및 저장

- GitHub Pages 사이트는 **공개**되지만, 공부 기록은 별도 Supabase 데이터베이스에 저장합니다.
- 이메일/비밀번호 로그인 후 본인 계정의 기록만 읽고 쓸 수 있도록 **행 단위 보안 정책(RLS)**을 적용했습니다.
- Supabase **공개용(publishable) 키**만 웹 코드에 포함되어 있습니다. 비밀 키는 저장하지 않습니다.
- 기록은 계정 단위로 분리됩니다. 부모님과 아들이 기록을 공유하려면 **같은 가족 계정**으로 로그인하세요.
- 다른 사람이 가족 계정의 비밀번호를 알면 기록에 접근할 수 있으므로 안전하게 보관하세요.
- 다른 기기에서 입력 중이라면 저장 상태가 '저장 완료'인지 확인한 후 새로고침하세요. 동시 편집 시 마지막 저장 내용이 우선할 수 있습니다.

## 미완료 과제 내일로 미루기

- 완료하지 못한 과제 오른쪽의 **내일로 →** 버튼을 누르면 기존 날짜에서 빠지고 다음 날 **📦 미룬 할 일** 목록으로 이동합니다.
- 미룬 과제는 다시 **내일로 →** 버튼을 눌러 하루씩 추가로 미룰 수 있습니다.
- **원래 날짜로** 버튼을 누르면 처음 계획했던 요일로 돌아옵니다.
- **일요일 → 다음 주 월요일**로도 이동되며, 휴식일인 토요일로 옮긴 과제도 표시됩니다.
- 가족 계정의 Supabase 데이터베이스에 미룬 상태를 별도로 저장하고 기기 간 공유합니다.
- 원래 주간 계획표 자체를 변경하지 않으며 완료 처리된 항목은 미룰 수 없습니다.


## 날짜별 할 일 순서 및 직접 추가

- 각 할 일 **가장 오른쪽의 ≡ 손잡이**를 손가락으로 약간 길게 누르고, 원하는 위치로 끌어 놓으세요. PC에서는 마우스로 끌어 놓습니다.
- 키보드는 ≡ 손잡이에 포커스한 후 **위/아래 방향키**로도 순서를 조정할 수 있습니다.
- 순서는 **각 날짜별**로 따로 저장되며, 같은 가족 계정으로 로그인한 기기에서 공유됩니다. 기본 요일별 할 일 구성을 바꾸지는 않습니다.
- 목록 아래의 **＋ 이 날짜에 할 일 추가**에서 새 할 일 이름과 목표 시간(분)을 입력할 수 있습니다.
- 직접 추가한 할 일도 완료 체크·실제 시간 입력·내일로 미루기·삭제가 가능합니다.
- 직접 추가한 할 일과 미룬 할 일도 목표 시간·주간 통계·인쇄용 계획표에 포함됩니다.
- 변경 사항이 다른 기기에 보이려면 **저장 완료** 표시를 확인한 뒤 **기록 새로고침**을 누르세요.
